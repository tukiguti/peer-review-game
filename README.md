# 査読ゲーム (peer-review-game)

設定した1〜5枚の研究カードを引き、その場ででっち上げた研究内容を語り、他プレイヤーが「査読が通るか」を秘密投票する対面パーティゲーム。

> 「量子コンピューティング」×「エスノグラフィ調査」×「被験者は3人まで」
> ——このカード構成で、それらしい研究を語れ。過半数が Accept すれば採択。

- **形態**: Webアプリ。起動時に**オフライン（端末1台を囲んで対面）**／**オンライン（各自のスマホから部屋に参加）**を選ぶ
- **人数**: 3〜8人
- **1プレイ**: 5人 × 2周でおよそ25分

## 遊び方

1. **抽選** — 1〜5リールのスロットが回り、設定した種類のカードが決まる
2. **発表** — 発表者が60秒で研究内容を語る（制約カードの無茶ぶりは無視できない）
3. **査読** — 発表者以外が `Accept` / `Reject` を投票。既定は**せーの（全員同時公開）**、設定で**パスプレイ（1人ずつ秘密投票）**にも切替可
4. **判定** — 過半数 Accept で採択。発表者に +1点（満場一致なら +2点）。査読者に点は入りません
5. **リバッタル** — 不採択なら発表者が30秒だけ弁明でき、そのあともう一度投票します（1手番に1回）

カード構成は各スロットを「分野」「手法」「制約」「新規性」から自由に選び、さらに「おまかせ」「真面目」「ネタ」を個別に指定できます。たとえば「分野・真面目／分野・ネタ／制約・ネタ」のような混在も可能です。既定は「査読4枚（分野・手法・制約・新規性）」で、ほかに「標準3枚」「分野×3」「ライト2枚」「盛り盛り5枚」のプリセットもあります。

Accept の目安は「全カードを使った」「カード同士のつなぎ方に筋が通った」「制約への工夫に納得できた」の3項目です。最終結果では総得点1位の「学会MVP」に加え、満場一致を最も多く取った「話術賞」、Reject を最も多く出した「Reviewer #2 賞」、Accept を最も多く出した「オープンアクセス賞」を表彰します。

カードは汎用・ソフトウェア工学・セキュリティ・情報科学・心理学・生物医学・食料理・経済社会・ファッションの9ジャンル、真面目寄せ・ネタ寄せの両方を収録しています（分野・手法・制約・新規性の4デッキ、全771枚）。ジャンルを絞れば分野の近い人だけで、全部にすれば異分野の衝突が楽しめます。

## オンラインプレイ

司会が部屋を作り、表示される**部屋コード・QRコード・リンク**のどれかを共有すると、各自のスマホから参加できます。発表のあと全員が自分の端末で秘密に投票し、**揃った時点で自動的に一斉公開**されます。ジャンル・カード構成・周回数は司会がロビーで決められます。

通信が切れても、同じ端末なら自動で再接続して同じ席に戻ります（画面の消灯やアプリの切り替えを想定）。進行が止まったときのために、司会は投票の締め切りと手番の放棄ができ、司会自身が切断中なら他の参加者が進行を引き継げます。

## 開発

```bash
npm install
npm run dev         # 画面 (http://localhost:5173)
npm run dev:worker  # オンライン用の部屋サーバ (wrangler, :8787)
npm run test        # 得点計算・抽選ロジックのユニットテスト
npm run build
```

オンラインを触るときは `dev` と `dev:worker` を両方立ち上げます。`dev` は `/api` を wrangler に転送します（ポートを変えたい場合は `WORKER_URL` を指定）。

公開前の確認項目は [docs/spec.md](docs/spec.md) にまとめています。変更時は `npm test` と `npm run build` の両方を通してください。

ブランチ運用: `main` は本番なので直接触らず、`feature/*` → `develop` で統合し、検証後に `develop` → `main` へマージします（このマージが本番リリース）。

デプロイ: main への push で自動配信。本番は **Cloudflare Worker（静的配信＋オンラインの部屋サーバ・無料枠）** → https://review-game.tukiguti.com/
（GitHub Pages のミラーも維持: https://tukiguti.github.io/peer-review-game/ ／ `base` はビルド時に自動で出し分け。ミラーは静的配信のみでオンラインは動きません）
